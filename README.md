# Т-Банк — демо-прототип (Telegram Mini App)

Мобильный прототип банковского приложения в визуальном языке нового приложения Т-Банка:
светлый фон, белые карточки, синий акцент, жёлтый бренд. React + TypeScript + Vite + Tailwind CSS,
интерфейс рассчитан на ширину до 430 px. Все данные хранятся в `localStorage`.

> Это неофициальный демонстрационный прототип. Он не связан с Т-Банком, не использует его API
> и не содержит реальных банковских данных.

## Запуск веб-приложения

```bash
npm install
npm run dev
```

Сборка: `npm run build`, предпросмотр сборки: `npm run preview`.

## Telegram Mini App + бот

### 1. Секреты

Скопируйте `.env.example` → `.env` и заполните:

```bash
BOT_TOKEN=токен_от_BotFather
WEBAPP_URL=https://ваш-https-url
```

Токен **не** храните в README и не коммитьте `.env`. Если токен уже светился в чате или репозитории — перевыпустите его в [@BotFather](https://t.me/BotFather) → `/revoke`.

### 2. HTTPS для Mini App

Telegram открывает только HTTPS. Варианты:

**Быстрый тест (туннель)** — в одном терминале:

```bash
npm run build
npm run preview
```

В другом:

```bash
npm run tunnel
```

Скопируйте выданный `https://….lhr.life` в `WEBAPP_URL` в `.env` и перезапустите бота.

Не используйте localtunnel (`loca.lt`) для Mini App в Telegram — там появляется страница с вводом IP, и WebView часто зависает.

Запасные варианты: `npm run tunnel:cf` (cloudflared) или постоянный хостинг Cloudflare Pages / Vercel / GitHub Pages.

**Продакшен** — задеплойте `dist/` на Cloudflare Pages / Vercel / GitHub Pages и пропишите постоянный URL в `WEBAPP_URL`.

### 3. Запуск бота

```bash
npm run bot
```

Бот:

- отвечает на `/start` кнопкой **Открыть банк**;
- ставит кнопку меню чата на Mini App;
- использует `WEBAPP_URL` из `.env`.

После смены URL перезапустите бота.

### 4. Проверка в Telegram

1. Найдите своего бота в Telegram.
2. Нажмите **Start** → **Открыть банк** (или кнопку меню).
3. Должен открыться этот интерфейс внутри Telegram.

## Экраны

- **Главная** — фокусный вид с балансом, быстрые действия, карта Black, кэшбэк,
  аналитика расходов по категориям и последние операции.
- **Платежи** — поиск по услугам, переводы по номеру телефона и карты, плитки услуг,
  последние платежи.
- **История** — поиск, фильтры (Все / Пополнения / Переводы / Расходы), итоги месяца
  и группировка по дням (Сегодня, Вчера, 25 октября).
- **Профиль** — данные клиента, баланс, Т-Банк Pro, доступ к конструктору и сброс демо-данных.
- **Детали операции** — нижний лист со статусом, суммой, реквизитами, справкой,
  повтором операции и удалением записи.
- **Конструктор операций** — траты, переводы, пополнения, баланс, сброс демо-данных.

## Данные

Ключ `localStorage` — `orbita.bank.state.v1`. При первом запуске создаются шесть
демонстрационных операций и баланс `148 250 ₽`. Кэшбэк и аналитика считаются из операций
текущего месяца.
